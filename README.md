# 🌸 Цветущий мир / Blooming World

Match-3 игра: **100 уровней в 10 главах-эрах** — сад эволюционирует от каменной
«Пустоши» до сияющего «Золотого сада». Параметрический генератор уровней
(одна формула — легко расширить до 10 000 уровней).

## 🎮 Как играть

**Самый простой способ — открыть одну кнопку:**

1. Онлайн: `https://kaistramador.github.io/blooming-world/` (GitHub Pages, без Cloudflare)
2. Локально: скачайте `index.html` и откройте двойным кликом — сборка не нужна.

Прогресс (звёзды, монеты, бустеры, скины, статистика) сохраняется автоматически
в localStorage браузера под ключом `blooming-world-save-v1`.

## ✨ Возможности

- **Два режима**: своп-матчи (3+ в ряд) и «взрывные» босс-уровни (каждый 10-й) — тапай группы из 2+
- **Спец-фишки**: ракеты ⇢ ⇣ (4 в ряд), бомба ✹ (Г/Т-комбо), радуга ❈ (5 в ряд)
- **Препятствия**: камни с запасом прочности (HP-точки), пустоты на поле
- **Бустеры**: 🔨 молоток, 💣 бомба, ⚡ молния, 🔀 перемешать, ↩️ отмена хода, ➕5 ходов
- **Магазин**: 10 скинов камней, 24 аватара, 12 рамок, 10 стилей имени, 18 эффектов
- **Двуязычный интерфейс**: RU / EN (переключается в Профиле → Настройках)
- **Доступность для дальтоников**: каждая фишка имеет уникальный силуэт
  (треугольник / ромб / шестиугольник / круг / квадрат / звезда) + канты,
  палитры всех эр построены на якорях Okabe-Ito с фиксированным порядком оттенков
- **Звук**: мини-синтезатор WebAudio, без аудиофайлов

## 🛠 Версия на Next.js (web-app/)

```bash
cd web-app
bun install        # или npm install
bun run dev        # http://localhost:3000
```

## 🔧 Технические детали

- Движок `index.html` — 1:1 порт `web-app/src/lib/game/engine.ts` (swap/tap,
  каскады, спец-комбо, камни, бутоны, бустеры), проверен unit-тестами
- Формат сохранения совместим с версией Next.js (`{state: {...}, version: 0}`)
- 100 уровней генерируются формулой от номера уровня (seed `lv*9176+11`),
  у каждого уровня фиксированные цели, ходы и пороги звёзд
- Рейтинг — детерминированные боты (seed `20261107`), локальный игрок вставляется
  по (уровень, звёзды)
