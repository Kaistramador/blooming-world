# ROADMAP — «Цветущий мир» (Blooming World)

> Кандидаты волн. **Ни одна волна не стартует без явного слова игрока.**
> База: MVP Task 1 + доступность Task 2 (см. STATE.md §2).

| Волна | Суть | Оценка объёма | Примечания |
|---|---|---|---|
| **A. Калибровка сложности по фидбеку** | Игровой прогон игроком первых глав → правки кривой (пошаговые цели 42+3×глава — стартовые значения из симуляции); при необходимости — ретро-калибровка камней/боссов | Малая | Требует живого фидбека игрока, не гонки ассистента |
| **B. Онлайновый рейтинг вместо ботов** | Реальный бэкенд в этом же Next-приложении (API-роуты + БД), вставка игрока в таблицу по (уровень, звёзды); анти-чит-минимум (санитизация сабмитов); боты остаются как «история» для одиночных режимов | Средняя | В App Router уже есть `src/app/api/route.ts` как точка входа; Без Cloudflare — хостинг решит игрок |
| **C. Масштаб 10000 уровней** | `TOTAL_LEVELS=10000` в `levels.ts` + генерация карты глав (пагинация/группировка эр), баланс дальних глав, миграция сейва (аддитивная) | Средняя | Механика готова к масштабу; работа в основном UI карты и баланса |
| **D. События и удержание** | Ежедневные задания, «уровень дня» (детерминированный по дате), достижения, сезонная косметика в магазин | Большая | После B — события пишут в тот же бэкенд |
| **E. Мобильная упаковка** | Capacitor-обёртка веб-версии (движок уже чистый TS, store — localStorage-совместимый); проверки WebAudio/viewport на Android/iOS | Средняя | Решение игрока о магазинах/подписях |
| **F. A11y-волна 2** | Настройки доступности: масштаб фишек, высокий контраст фона поля, обучающая карточка «фигуры цветов», редуцированная анимация (prefers-reduced-motion уже частично учтён) | Малая | Логичное продолжение Task 2 |
| **G. Юр-гигиена перед публикацией** | Проверка перед выходом на площадки: тексты, лицензии шрифтов/эмодзи-наборов,privacy-политика (localStorage only), возрастные рейтинги | Малая | Принцип §5.3 STATE.md уже соблюдается |

**Порядок не фиксирован** — игрок называет волну, ассистент детализирует план в начале сессии и заносит результат в worklog.
